# SoftGrowTech-Quiz-Game
A simple GUI based Quiz game made by Java                                                                                      Gameplay Features:
# Featuers
1.10 Java Questions — covers real Java topics like data types, OOP, JVM, exceptions, collections, and more.
2.4 Answer Options — every question has 4 choices (A, B, C, D) to pick from.
3.Instant Color Feedback — clicked button turns green if correct, red if wrong. The correct answer also highlights green automatically.
4.Explanation After Every Answer — a one-line explanation appears below the buttons telling you why the answer is right or wrong.
5.Live Score Display — score updates in the top bar after every answer in real time.
6.Scoring System:
Correct answer → +10 points
Wrong answer → −3 points (negative marking)
Maximum possible score → 100 points


7.Question Progress Tracker — top bar shows "Question 3 of 10" so you always know where you are.
8.Grade System at the End:
100% → S (Perfect)
80%+ → A (Excellent)
60%+ → B (Good)
40%+ → C (Fair)
Below 40% → D (Keep studying)

9.Results Popup — shows final score, correct count, wrong count, accuracy percentage, and grade.
10.Play Again Option — after results, player can restart the quiz or exit cleanly.
11.Button Locking — once you click an answer, all buttons are disabled so you cannot cheat by clicking again.
12.Next Button Logic — Next button only appears after answering, and changes to "See Results" on the last question.          

# Technologies Used
1. Java (Programming Language)
2. javax.swing (GUI Library)
3. java.awt (Abstract Window Toolkit)
4. java.awt.event (Event Handling)
5. JDK (Java Development Kit)
6. JVM (Java Virtual Machine)
